# Онлайн-магазин косметики

## Об'єкт моделювання
Життєвий цикл поля `order_status` сутності **Замовлення (Order)** у формі Машини станів.

## Опис станів та переходів
* **Draft (Чернетка):** Початковий стан при кліку на «Оформити замовлення». Система очікує введення адреси доставки.
* **Validated (Перевірено):** Перехід після `validateAddress()`. Тут сервер фіксує ціну косметики через `recordItemsPrice()`.
* **Paying (В процесі оплати):** Тимчасовий стан після виклику `processPayment()`. Система очікує на відповідь від банку.
* **PaymentError (Помилка оплати):** Стан після отримання `PaymentFailed` від банку. Система пропонує клієнту спробувати ще раз іншою карткою за допомогою `retryPayment()`.
* **Rejected (Відхилено):** Фінальний статус скасування замовлення (якщо користувач сам закрив вікно оплати або ліміт спроб вичерпано).
* **Paid (Оплачено):** Стан після успішного списання коштів. Система запускає паралельні фонові процеси логістики.
* **Packing & Shipping (Збірка та відправка):** Стан паралельного виконання дій, коли склад збирає коробку, а сервер викликає API пошти для генерації трек-номера.
* **Shipped (Надіслано):** Фінальний успішний статус замовлення після передачі посилки в службу доставки. Процес завершено.
